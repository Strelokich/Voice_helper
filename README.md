# Голосовой ассистент локальный

Десктопное приложение с распознаванием русской речи (офлайн, через Vosk),
системой команд «фраза - действие», с возможностью подключения к **BionicGPT** и любым
другим нейросетям через OpenAI-совместимый API (OpenAI, Claude, свои
провайдеры).
С открытым кодом и очень прост, я буду очень рад если кто то его захочет модифицировать и улучшить. 

## Возможности

- 🎙 **Офлайн-распознавание речи на русском** через [Vosk](https://alphacephei.com/vosk/) — работает полностью локально, без интернета и без обращения к каким-либо облачным API распознавания речи (Google/Yandex не используются).
- ⚡ **Гибкая система команд**: любая фраза привязывается к действию (открыть программу/сайт, выполнить shell-команду, сказать время/дату, управлять громкостью и т.д.) через удобный GUI, без правки кода.
- 🧠 **Подключение к BionicGPT** — self-hosted нейросеть с OpenAI-совместимым API. Задайте `base_url` вашего инстанса — и голосовые запросы («спроси бионика …») будут уходить прямо туда.
- 🔌 **Сторонние провайдеры "из коробки"**: OpenAI (ChatGPT), Anthropic (Claude), а также произвольный OpenAI-совместимый API (OpenRouter, LocalAI, LM Studio, Together AI и т.д.) — всё настраивается в GUI, без изменения кода.
- 🗣 Каждый провайдер активируется своей голосовой фразой — можно держать одновременно несколько нейросетей и переключаться между ними голосом.
- 🔊 Озвучивание ответов через `pyttsx3` (офлайн TTS).
- 🎨 Интерфейс на PyQt6: тёмно-фиолетовая неоновая тема, анимированный индикатор прослушивания, подробное окно настроек с вкладками.

## Установка

1. Убедитесь, что установлен Python 3.10+.
2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. **Скачайте офлайн-модель Vosk для русского языка**:
   - Перейдите на https://alphacephei.com/vosk/models
   - Скачайте `vosk-model-small-ru-0.22` (компактная, ~45 МБ, для повседневного использования)
     или `vosk-model-ru-0.42` (крупная, точнее распознаёт)
   - Распакуйте архив в папку `models/` внутри проекта (или в любое другое место)
   - При первом запуске укажите путь к распакованной папке в **Настройки → Распознавание → Папка модели Vosk**

4. **(Только Linux)** Для синтеза речи нужен `espeak-ng`:

   ```bash
   sudo apt install espeak-ng
   ```

   На Windows и macOS `pyttsx3` использует системные голоса (SAPI5 / NSSpeechSynthesizer) — ничего дополнительно ставить не нужно, но для русской речи на Windows должен быть установлен пакет русского голоса (Параметры → Время и язык → Речь).

## Запуск

```bash
python main.py
```

## Настройка команд

Откройте **⚙ Настройки → Команды → Добавить**. Укажите:
- **Фразу-триггер** — например, «включи музыку»
- **Тип совпадения** — фраза должна содержаться в распознанном тексте (`contains`),
  совпадать полностью (`exact`) или быть началом фразы (`startswith`)
- **Действие** — одно из встроенных: `open_app`, `open_url`, `run_command`,
  `say_time`, `say_date`, `say_text`, `system_volume`
- **Параметры** действия — например, для `open_url` укажите `url: https://youtube.com`

Новые типы действий легко добавить программно — см. `actions/builtin_actions.py`,
функция `register_action(name, func)`.

## Настройка подключения к BionicGPT и другим нейросетям

Откройте **⚙ Настройки → Нейросети → Добавить**:

| Поле | Что указать |
|---|---|
| Тип | `bionicgpt` для вашего инстанса BionicGPT, `openai` для OpenAI, `anthropic` для Claude, `openai_compatible` для любого другого OpenAI-совместимого API |
| Base URL | Адрес API, например `http://localhost:3000/v1` для локального BionicGPT |
| API-ключ | Ключ доступа (для BionicGPT создаётся в его интерфейсе: Team Settings → API Keys) |
| Модель | Имя модели, настроенной на стороне провайдера |
| Фраза-активатор | Например, «спроси бионика» — всё, что скажете после этой фразы, отправится в нейросеть |

Нажмите **«Проверить соединение»**, чтобы убедиться, что провайдер отвечает,
прежде чем сохранять.

Можно добавить сколько угодно провайдеров одновременно — ассистент сам
определит, к какому из них обращён вопрос, по фразе-активатору.

## Структура проекта

```
voice_assistant/
├── main.py                    # точка входа
├── config/
│   └── config_manager.py      # хранение всех настроек в JSON
├── core/
│   ├── speech_recognizer.py   # Vosk (офлайн) + онлайн-движки
│   ├── tts.py                 # синтез речи
│   ├── ai_providers.py        # BionicGPT / OpenAI / Anthropic / кастомные API
│   ├── command_engine.py      # сопоставление фраз с командами и провайдерами
│   └── assistant.py           # координатор без GUI-зависимостей
├── actions/
│   └── builtin_actions.py     # встроенные действия для команд
└── ui/
    ├── theme.py                # тёмно-фиолетовая неоновая тема (QSS)
    ├── main_window.py          # главное окно
    ├── settings_window.py      # окно настроек (5 вкладок)
    └── widgets/
        └── neon_orb.py          # анимированный индикатор состояния
```

## Известные ограничения

- Распознавание Vosk рассчитано на потоковую речь через микрофон в реальном
  времени; для распознавания заранее записанных аудиофайлов потребуется
  небольшая доработка (Vosk это тоже умеет, но здесь не включено).
- `system_volume` для Windows использует утилиту `nircmd` (нужно скачать
  отдельно и положить в PATH) — это самый надёжный способ управлять
  громкостью без дополнительных Python-библиотек.
